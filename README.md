# Нейро-мед

Локальное демо учебного чата по гигиене. Точка входа — `frontend/index.html`.

## Запуск

Откройте PowerShell в корне проекта. С установленным Node.js выполните:

```powershell
node frontend/serve.mjs
```

Откройте [http://127.0.0.1:4173](http://127.0.0.1:4173). Для остановки нажмите `Ctrl+C` в терминале. Устанавливать пакеты не нужно.

## Демо-режим

«Помощь с вопросом» подставляет редактируемый шаблон в поле ввода. Если там есть черновик, чат запрашивает подтверждение замены. Через «Управление шаблонами» можно создавать, редактировать и удалять любые шаблоны.

Первый отправленный вопрос добавляет диалог в историю. Меню с многоточием открывает удаление чата с подтверждением. Отправленные сообщения и шаблоны хранятся в localStorage, включая пустые списки после удаления. Формат ранее сохранённых диалогов поддерживается.

Кнопка «Редактировать сообщение» открывает редактор на месте отправленного вопроса. Основное поле ввода сохраняет свой черновик. Демо-ответ строится по новому тексту и истории до вопроса. При правке более раннего вопроса чат предупреждает, что последующие сообщения будут заменены. Новое продолжение появляется после успешного сохранения в localStorage. При сбое редактор сохраняет текст для повторной попытки.

Начальные диалоги, шаблоны, ответы, фрагменты и страницы материалов заданы в `frontend/demo-data.js`. «Открыть страницу» показывает демонстрационный материал на указанной странице в новой вкладке. API и библиотека кафедры ожидают подключения.

## Проверка

26.11.2026 в Chrome пройдены браузерные сценарии на 360 × 800, 768 × 900 и 1440 × 900 px. На каждой ширине проверены отправка вопроса, переход к странице источника, создание, изменение, выбор и удаление шаблона, подтверждение замены черновика, удаление текущего и другого чата и сохранение пустых списков после перезагрузки. Дополнительно проверены клавиатурная навигация, режим уменьшения анимации, загрузка диалога прежнего формата и удаление чата во время ответа в одной и в двух вкладках.

Редактирование отправленных сообщений проверено в Chrome на 1440 и 360 px. Пройдены правка последнего и более раннего вопроса, отмена, проверка текста, сохранение черновика, имитация ошибки записи и повторная попытка. После перезагрузки правки сохраняются, а новый демо-ответ использует контекст до изменённого вопроса.
